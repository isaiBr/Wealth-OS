# Correos de ejemplo — Interbank

Pon aquí un archivo .txt por cada correo, con el asunto y el cuerpo completo
tal cual (puedes cambiar montos/nombres si quieres, pero NO cambies la
estructura, el remitente, ni las etiquetas/palabras del banco).

Formato sugerido para cada archivo, ej. `compra-debito-1.txt`:

De: (remitente exacto, ej. notificaciones@notificacionesbcp.com.pe)
Asunto: (asunto exacto del correo)
---
(cuerpo completo del correo, texto plano o pegado del HTML)

Tipos que necesito, uno de cada uno si los tienes:
- compra-debito-1.txt
- compra-credito-1.txt
- transferencia-enviada-1.txt
- transferencia-recibida-1.txt
- pago-servicio-1.txt
- compra-cuotas-1.txt   (si tienes alguna compra "cuota X/Y")
- pago-tarjeta-credito-1.txt
